One line about office life for the [Make the AI Judge Laugh](https://make.fun/bounty/u-rama-melon-make-the-ai-judge-laugh-302d0825) bounty on make.fun — a blind-judged contest where a judge model picks the funniest office joke head to head. The entry is a single line, under 200 characters, about the one office policy that can only survive inside the thing it bans.

> We have a 'no-meeting Wednesdays' policy. It is observed every Wednesday, in a meeting about why we keep breaking it.

## Run it

```sh
node main.ts
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), enforcing the gate first: a single non-blank line of 1–199 characters.
